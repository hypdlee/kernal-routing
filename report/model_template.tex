\section{Setup and coverage}\label{sec:setup}

\paragraph{Backbone.} \V{modelname}, adapted to $32\times32$ and
$64\times64$ inputs as recorded in \texttt{src/models}. Width 64 is the
standard network; widths 32 and 16 scale every channel count by $1/2$
and $1/4$. Dynamic layers follow the ResNet-18 rule literally (every
$k\times k$ convolution with $k>1$ inside the blocks; stem, $1\times1$
convolutions, shortcuts, downsampling layers and head static): here
\V{placement}, \V{ndyn} layers. Initialisation: \V{initdesc}.

\paragraph{Size.} At CIFAR-100 width 64 the static network stores
\V{pstatic}\,M parameters and the $K=4$ \texttt{gap} network
\V{pgap}\,M, of which \V{prouter}\,K are router parameters
(Table~\ref{tab:config}). The bank adds \V{pbankadd}\,M to the static
network; the router is \V{prouterpct}\,\% of the static network's size.
The router is the ResNet-18 design (a two-layer MLP with hidden width
$C_{\text{in}}/4$ on the global descriptor), so its size grows with the
square of a layer's input channels while a depthwise kernel grows
linearly: where dynamic layers are depthwise, the routed arms carry many
more parameters than the bank. The \texttt{gap}$-$\texttt{uniform}
routing term includes them.

\paragraph{Gate.} The first run, static, CIFAR-100, width 64, seed 0,
reached \V{gateacc}\,\% against a pre-registered floor of
\V{gatefloor}\,\%: \V{gateverdict}.

\paragraph{Coverage.} \V{nruns} of 132 runs are present; \V{nmissing}
are missing, of which \V{ndiverged} diverged (non-finite training loss).
\V{ndevgroups} group(s) ran with gradient accumulation because batch 128
did not fit in memory. Table~\ref{tab:cover} lists every missing run and
every deviation. Paired tests use the seeds both arms have; a verdict
computed on fewer than six pairs carries its $n$.
